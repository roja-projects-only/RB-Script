## The system

Ang broadcast ay isang tibok ng puso: **kinukuha ng programa ang pulso ng bayan** — ang mga pangyayari ng araw, ang bilis at bagal ng mga balita.

- **Vocabulary:** pulso (pulse), pintig (beat), tibok (thump), pulsohan (kunin ang pulso), bumibilis ang pintig (breaking/energy), humihina ang pintig (close). Nasasagot nito ang open hanggang close.
- **Sonic logo:** ang tibok mismo — ang pinakamadaling asset na i-source (recorded pulse o tatlong mababang percussive thumps ~72 bpm; mahina at mabagal sa close).
- **Payoff map (paid off ≥2 beses + bookend):**
  1. Open: heartbeat → slogan → split ID → unison `PULSO! PULSOHAN NATIN ANG BALITA!`
  2. Headline frame: `HAWAKAN NATIN ANG PULSO NG MGA PANGUNAHING BALITA…`
  3. Q&A: `…ANO KAYA ANG PINAKAMAHALAGANG DAPAT TANDAAN… TUNGKOL DITO?` (kaya question)
  4. Break tease: `…PULSUHIN ANG PALIGSAHAN AT ALIWAN…` + bumper na nangangako ng muling pagbabalik
  5. Re-entry: heartbeat returns + identity restated (`BABALIK TAYO SA D-Z-R-M…`)
  6. Soft block: `PINTIG NG PALIGSAHAN` / `PINTIG NG ALIWAN` launches
  7. Sign-off family: `PULSO SA BALITA / PALIGSAHAN / ALIWAN` (one-word swap, C10-style)
  8. Close: recap (`MULING PULSUHIN…`) → IDs → unison money line → **humihinang tibok** + slogan — sinasagot ang open.
- **Disiplina sa tunog:** isang sonic logo, 3 gamit lang (open, re-entry, close), hindi kailanman sa loob ng segment. Isang diegetic beep sa buong show (time check). Concept bilang container — ang news bodies ay plain na Filipino; walang metaphor sa loob ng balita.

## Why PULSO

- **Bukas na lane:** walang National entry (18/18 corpus) ang gumagamit ng pulse/heartbeat sound bilang identity; walang kapatid na draft ang humihipo nito (PALENGKE = palengke, HIMIG = awit, TALA = bituin, DALUYONG = alon, BATINGAW = kampana).
- **Audio-native:** ang sonic logo ay ang pinakamadaling i-produce sa lahat ng kandidato.
- **Speakable:** `PULSOHAN NATIN ANG BALITA!` — 8 pantig, open vowels, madaling sabihin nang sabay-sabay.
- **Ang truth hook ay nakasakay sa metaphor** (`TUNAY ANG PINTIG, TUNAY ANG BALITA`) sa halip na hubad na truth slogan — may sariling kawit, hindi genre-default lang.
